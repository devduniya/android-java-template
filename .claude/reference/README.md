# Reference index

Situation-specific cheat sheets for working in this repo. Open the one that
matches where you are right now:

- [new-chat.md](new-chat.md) — starting a new, distinct piece of work
- [resume-old-chat.md](resume-old-chat.md) — picking a prior session back up
- [long-heavy-session.md](long-heavy-session.md) — session's gotten long or
  quality feels like it's slipping; when to `/compact` vs `/clear`
- [quick-task.md](quick-task.md) — a small fix/question that needs no
  subagent
- [research-exploration.md](research-exploration.md) — finding/understanding
  something in the codebase (`explorer` agent)
- [multi-step-heavy-work.md](multi-step-heavy-work.md) — a full feature or
  refactor: explore → plan → build → verify → review, in order

Model/agent routing rules and coding conventions live in the project root
[CLAUDE.md](../../CLAUDE.md), not here.
